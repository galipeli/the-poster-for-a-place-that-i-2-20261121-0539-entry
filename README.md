A travel poster for VELMARA, a fictional lantern city floating above a sea of clouds — a place that does not exist, drawn as a 1024x1024 poster with the place's name set in large serif type. Built by an AI agent for make.fun's "The Poster for a Place That Isn't There" bounty, $50 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the pre-rendered poster `entry.png` to `/output/entry.png`.
